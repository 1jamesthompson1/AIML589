# Report diagrams

Hand-written TikZ diagrams for the report. Each `<name>.tex` is a bare `tikzpicture` with no preamble, so the report pulls it in with one line:

```latex
\cdiagram[placement]{name}{Caption text}
```

`\cdiagram` is defined in `docs/common.tex`. It wraps the file in a figure environment, puts the caption in the chapter (edit it there), and sets the label to `fig:<name>`, so `\figref{name}` works. Figures generated by code (plots, tables) stay in `code/figures/`.

To add a diagram, create `<name>.tex` here, check it renders in the report, then call `\cdiagram` where it belongs.
