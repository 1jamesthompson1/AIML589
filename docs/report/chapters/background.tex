\subsection{Building LLMs as autoregressive self attention}
\label{subsec:llms}

Probabilistic model of language. Guesses the next token

Definitions:
$V$ is the vocabulary size, The model parameters are $\theta$. The model is a function $f_\theta$ that maps a prompt and a completion prefix to logits over the vocabulary. 

Let a training example consist of a prompt (system + user) tokenised as
$x = (x_1, \dots, x_P)$ and a completion (assistant answer) tokenised as
$y = (y_1, \dots, y_T)$, with $T$ the completion length.

The model is
autoregressive, so the probability of the completion factorises over tokens:

\begin{equation}
  p_\theta(y \mid x) = \prod_{t=1}^{T} p_\theta\left(y_t \mid x, y_{<t}\right),
  \qquad y_{<t} = (y_1, \dots, y_{t-1}).
\end{equation}
The probability of the next token is given by a softmax over the logits:
\begin{equation}
  p_\theta\left(y_t \mid x, y_{<t}\right)
  = \frac{\exp f_\theta(x, y_{<t})_{y_t}}{\sum_{v=1}^{V} \exp f_\theta(x, y_{<t})_v}.
\end{equation}

\section{Understanding the values of humans and AI systems}
\label{sec:values}

As discussed in \ref{sec:values} one can infer of a value as either explicit statement or implicitly revealed through behaviour. yet a value is a latent object that is not directly observable. \footnote{In an AI system like a LLM it is theoretically possible to extract the 'values' as a set of weights/activations; much like how human values could be extracted with brain scans. However at present day this is infeasible and potentially impossible due to the concept of values being inherently fuzzy abstract concept used to describe diffuse mechanics.}

\subsection{Value surveys}

A straightforward method of eliciting and understanding the values is to ask them directly. These are either done in abstract ways or in more contextual settings (\termref{value-survey}).

Value questionnaires are developed in line with various theories of values like PVQ...

On the other hand value surveys are more contextual and ask people specific questions. \cite{NZAVS2025,WVS2020}. These can be post hoc mapped to value theories however as they are not a direct measure this is not as reliable. Importantly though these provide a more direct measure of the actual downstream effects of people's values by for example gaining insights 

These value surveys can be used as training data...

\subsection{Dilemmas as a way to understand values}

A dilemma is a situations where there is no clear right answer and a tradeoff between competing values must be made \cite{EthicalDilemmasOverview}. In experimental research these dilemmas are hand crafted to create  clear decisions that reveal the values of the respondent. It is in this way that dilemmas can be used to understand the values of humans and AI systems.



A few datasets have been built to understand LLM values through large sets of moral, ethical and social dilemmas \cite{lourieScruplesCorpusCommunity2021,chiuDailyDilemmasRevealingValue2025,hendrycksAligningAIShared2023,scherrerEvaluatingMoralBeliefs2023}.
