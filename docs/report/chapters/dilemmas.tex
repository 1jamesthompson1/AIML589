In this chapter I test whether the models fine tuned on the survey data respond differently to various moral, ethical and value dilemmas. The goal here is to firstly answer \rqref{align} by comparing base models to fine-tuned models and then secondly use the model responses in \ref{chap:survey} to answer \rqref{prefer}. I do this by presenting models with self contained dilemmas across a wide range of NZ work contexts (namely public sector jobs). The model is asked to provide a response which describes what their decision would be. In this way we can compare the responses for differences between base models and fine-tuned models. Initially the methodology was going to test the model using agentic dilemmas, however this proved too difficult to get clean differences of value judgements. Therefore a soft pivot was conducted to use single response dilemmas instead. More information about the agentic dilemmas can be found in \ref{app:simulation}

\section{How the dilemmas were constructed}

The key way to construct the dilemmas was to create dilemmas that were relevant to the New Zealand population, sufficiently controversial and clear in the value tension.

\subsection{Targeted value tensions}

To guide the writing process of dilemmas I focused on a set of value tensions that were defined in the value space of Schwartz refined value system.

To do this I used Schwartz's refined value system \cite{schwartzOverviewSchwartzTheory2012} to identify the values in which the New Zealand population differs from the base LLM (Qwen 3.8 27B). To do this each of the questions in the World Values Survey (WVS) were mapped to the Schwartz value system. Then by seeing hte distribution of responses to the WVS questions we can identify the value tensions that are most different between the base model and the New Zealand population.  Furthermore given the circular nature of the Schwartz value system, each value has an inherent tension with opposite values (which are used to construct the candidate value tensions). The result of this can be found in \tabref{value-tensions-qwen3.8-27b}. 

\ctabl{value-tensions-qwen3.8-27b}{The value tensions identified in the WVS survey data. Each value tension is defined as the average difference between the questions that are mapped to either of the two values.}

1. Value tensiosn are defined based on circumplex structure of the Schwartz value system. The values are arranged in a circular structure, where adjacent values are compatible and opposite values are in tension with each other.
2. Each questions in the WVS survye is mapped to be relevant to one or more of the Schwartz values.
3. The tensions are then calculated by calculating the aggregate difference between the base model and the New Zealand population for each of the value tensions. Where a value tension is defined as the average difference between the questions that are mapped to either of the two values.

These value tensions are based on the motivational goals, that is what are people trying to achieve.
